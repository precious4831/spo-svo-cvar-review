# Disclosure scope

Included:

- Three short Python files containing statistical or non-parametric excerpts.
- Module-level explanations, input semantics, and source provenance.

Omitted:

- Training, fine-tuning, pretraining, and data-collection entry points.
- Complete SVO/RSSM belief networks, encoder, response decoder, actor and critics.
- SPO/PPO update routines, rollout buffers, loss assembly, and dual updates.
- Game-risk urgency construction and experiment-specific episode cost/budget logic.
- CARLA environments, scenario construction, reward functions, and NPC controllers.
- Hyperparameter sets, optimizer state, random-seed schedules, and launch scripts.
- Model checkpoints, datasets, trajectories, logs, videos, and experiment outputs.
- Local paths, credentials, machine configuration, and original repository history.

The repository supports inspection of the disclosed expressions. Reproducing
training or reported driving results requires additional materials outside
this release.
